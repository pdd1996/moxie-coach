## 说明项

1. **题数 156**：官方「面试经典 150 题」是 150，本底稿 156 = 150 + 方法论代表题 + 多线程选做。多出的 6 道：`242 有效的字母异位词`、`206 反转链表`、`704 二分查找`、`347 前 K 个高频元素`、`78 子集`（这 5 道是《刷题技巧.md》各阶段套路代表题，按「方法论从属于题单」保留），以及 `1114 按序打印`（多线程，`optional: true` 选做）。无需纠结精确 150。
2. **难度/标题/slug**：检索来源可能有出入，`5`/`300` 的 slug（含 "longest" 拼写）、`427`/`909`/`502` 等较新题可抽查。
3. **stage（阶段）映射**：按 PRD 4 阶段 + 我的判断分配，非官方分类。`数学`/`位运算`/`Trie`/`分治`/`设计` 这些 PRD 四阶段没明写的类别，我按就近归入（数学/位运算→阶段1，Trie/设计→阶段2，分治→阶段3）。可按你的方法论调整。
4. **pattern（套路）**：原型里已在 150 范围内的 33 题沿用你标过的 pattern+signal；其余 118 题的 pattern 用 LeetCode 分类名占位，**未细到「套路」粒度**（如「双指针（相向从后）」这种），需你按《刷题技巧.md》细化。
5. **signal（判断信号）**：仅那 33 题有，其余 118 题留空，刷到时再补。
6. **`entry` 字段不在本文件**：按 v1.2 设计，`entry` 由 F2 贴题时从 skeleton 解析存入 problem 记录，不在元数据预填（见 S0-judge / S2-F2）。
