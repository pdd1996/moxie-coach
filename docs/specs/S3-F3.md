# S3-F3 — 刷题尝试流程（P0 · 对应 PRD F3）

## 目标
打开已贴题 → 置 `in-progress`、计时自动开始（Easy 15/Medium 25/Hard 25，可配置）；编辑器写码、运行用例逐条判定；自解通过记 `self-solved`（进 SRS）；超时软提醒；可暂停；可跳过（`skipped`）；V1.0 无题解兜底。

## 验收标准（来自 PRD F3，v1.2 修订）
- 从打开到跑通用例全流程无刷新。
- 暂停后历史记录含暂停时长。
- 切语言后 `lastLang` 持久化且重开默认正确。
- 超时软提醒（计时器变红 + 「看题解」高亮），不弹窗锁死。
- 本地无题解点「看题解」时提示手动粘贴（V1.0 兜底）。

## 数据读写点
- 进入 attempt：置 `status = 'in-progress'`
- 每次暂停/结束：append `history`（`phase: 'attempt'`、`outcome`、`elapsedMin`、`pausedMin`、`peekCount: 0`、`lang`）
- 自解通过：`status = 'self-solved'`，调 S6 排期（首间 3 天，`srsLevel = 0`）
- 跳过：`status = 'skipped'`，不排期
- 切语言：写 `lastLang`
- 运行用例：不写数据（判题只读）

## 涉及文件
- `src/pages/ProblemView.tsx` — attempt 态（原型已验证，接持久化 + 真判题）
- `src/components/Timer.tsx` — 计时/暂停/重置（原型已有，补暂停时长上报）
- `src/lib/judge/runner.ts` — 真判题（S0-judge）
- `src/lib/srs.ts` — 排期调用

## 依赖前序 spec
S0-scaffold、S0-data-layer、S0-judge、S1-F1、S6-F6（排期规则）

## 实现要点
- 计时器到点：`onTimeout` 只设软提醒文案 + 高亮看题解，不锁界面（原型已是软提醒，保留）。
- 暂停：计时器累计 `pausedMin`，存入 history。
- 「自解通过」按钮 `disabled={!allPass}`（原型已有）。
- 「去 LeetCode 提交」打开 `leetcodeUrl(problem)`（原型已有）。
- 「只看题解不刷」→ `skipped`，不进默写、不排期。
- V1.0 兜底：点「看题解」时若 `!problem.solution`，弹提示「暂无题解，请手动粘贴（V1.1 起 AI 可生成）」，停在 attempt 不进 solution 态。
- 切语言：编辑器按语言分存草稿（`codeByLang`），显示目标语言的草稿（没写过则该语言骨架），两语言互不覆盖。修订 v1.2 的「attempt 保留当前 code」方案--原方案切到 JavaScript 仍显示 Python 代码（用户反馈 bug）。

## 不做
- 不做 AI 分层提示（F7.1，V1.1）。
- 不做正式判题提交（去 LeetCode 网站）。
