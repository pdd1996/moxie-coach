# S5-F5 — 一句话笔记（P0 · 对应 PRD F5）

## 目标
默写通过/失败后弹笔记，固定提示「什么时候用这个套路？」，存入题目；题目详情常驻展示，复习入口先看笔记再默写。

## 验收标准（来自 PRD F5）
- 笔记随题目持久化。
- 复习入口（仪表盘/题单）可见笔记；复习时先看笔记再默写。
- 笔记弹窗可跳过（失败时可选）。

## 数据读写点
- 写 `problem.note`（一句话/多行）

## 涉及文件
- `src/pages/ProblemView.tsx` — 笔记弹窗（原型已有，接持久化）
- `src/components/ProblemNote.tsx` — 常驻笔记展示（可内联）

## 依赖前序 spec
S0-scaffold、S0-data-layer、S4-F4（笔记在默写后触发）

## 实现要点
- 弹窗 placeholder 用 `problem.signal` 引导：「看到「{signal}」就用 {pattern}」。
- 通过/失败都可写笔记；失败时弹窗「先跳过」可略过。
- 笔记在默写态顶部常驻显示（原型 reproduce 态已展示「你的笔记」，保留）。
- 复习入口（题单/仪表盘）hover 或详情可看笔记——题单加笔记图标/tooltip。

## 不做
- 不做多笔记/版本（一句话即可）。
- 不做 AI 错题复盘提示卡（F7.4，V1.1，写 `hintCard` 字段）。
