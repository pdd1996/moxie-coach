# S4-F4 — 默写模式（P0 · 对应 PRD F4）

## 目标
看完题解后或复习日直接进默写：题解收起、代码清空只留签名、重计时；偷看题解允许但如实计数；通过/失败走 SRS。

## 验收标准（来自 PRD F4，v1.2 修订）
- 默写模式下题解默认收起。
- 展开题解次数正确记录并在结果页显示。
- 首次通过 → `learned`；复习通过 → `learned` 且 `srsLevel` 升级，达顶 → `mastered`；失败 → `pending-review`、`srsLevel` 重置 0、排 3 天。
- 复习日进入时 `status = 'reviewing'`，history `phase = 'review'`。

## 数据读写点
- 进入默写（首次）：`phase` 本地态切 reproduce
- 进入默写（复习）：置 `status = 'reviewing'`
- 偷看：累加 `peekCount`（本地态 + 写入当次 history）
- 通过：`status = 'learned'`（或 `mastered` 若达顶），`srsLevel += 1`，append history `phase: reproduce|review, outcome: pass`，调 S6 排下一间隔
- 失败：`status = 'pending-review'`，`srsLevel = 0`，append history `outcome: fail`，排 3 天

## 涉及文件
- `src/pages/ProblemView.tsx` — reproduce 态（原型已验证，接持久化 + 真判题）
- `src/lib/srs.ts` — 排期/升级/重置纯函数

## 依赖前序 spec
S0-scaffold、S0-data-layer、S0-judge、S6-F6

## 实现要点
- 进入默写：`code = skeleton[lang]`（清空只留签名）；无 skeleton 则保留 attempt 首行签名。
- 偷看计数：点「偷看一眼题解」`peekCount++` 并打开题解弹窗（原型已有，接持久化：存入本次 history 的 `peekCount`）。
- 通过按钮 `disabled={!allPass}`（原型已有）。
- 复习入口：仪表盘/题单点待复习题，若已贴题则直接进 reproduce 态（不重看题解），`status` 置 `reviewing`。
- history 的 `phase`：首次默写 `reproduce`，复习默写 `review`（A3 区分，F8 据此统计）。
- 通过后转 S5 笔记弹窗。

## 不做
- 不强制禁止偷看（诚实原则，允许但计数）。
- 不做 AI 边界审查（F7.2，V1.1）。
