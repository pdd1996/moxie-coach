# S6-F6 — 间隔复习 SRS（P0 · 对应 PRD F6）

## 目标
实现 SRS 排期引擎：`srsLevel` 升级、`nextReviewAt` 计算、复习队列聚合。覆盖 self-solved / learned / pending-review / reviewing 全路径。

## 验收标准（来自 PRD F6，v1.2 修订）
- 通过/失败后 `nextReviewAt` 与 `srsLevel` 计算正确。
- `self-solved` 题出现在复习队列。
- 跨天打开软件队列刷新正确。
- 掌握后不再排期；设置页可手动重置 `srsLevel` 回 0 重新刷。
- 间隔序列默认 `[3,7,14]` 可配置。

## 数据读写点
- 排期：写 `nextReviewAt = today + intervalsDays[srsLevel]`
- 通过：`srsLevel += 1`；若 `srsLevel === intervalsDays.length` → `status = 'mastered'`，清 `nextReviewAt`
- 失败：`srsLevel = 0`，`nextReviewAt = today + 3`（用 intervalsDays[0]）
- 读：队列聚合（在 S1-F1 仪表盘用）

## 涉及文件
- `src/lib/srs.ts` — 纯函数：`scheduleNext`、`advanceLevel`、`resetLevel`、`reviewQueue(problems, today)`、`suggestNew(problems)`

## 依赖前序 spec
S0-scaffold（类型，`srsLevel` 字段）、S0-data-layer

## 实现要点
- **`srsLevel` 语义**：0=刚通过待首复习，排期间隔用 `intervalsDays[0]`=3；通过一次复习后 `srsLevel=1`，下次用 `intervalsDays[1]`=7；…；`srsLevel` 到 `intervalsDays.length` 时 `mastered` 不再排。
- 首次通过（attempt 自解 / 首次默写通过）：`srsLevel = 0`，`nextReviewAt = today + intervalsDays[0]`。
- 复习通过：`srsLevel += 1`，若未到顶则 `nextReviewAt = today + intervalsDays[srsLevel]`，到顶 `mastered`。
- 复习失败：`srsLevel = 0`，`nextReviewAt = today + intervalsDays[0]`，`status = 'pending-review'`。
- 日期用 `YYYY-MM-DD` 字符串比较；`today` 由调用方传入（避免模块加载时硬编码，原型 mock 里 `today='2026-08-18'` 是反例）。
- `reviewQueue`：`nextReviewAt <= today` 且 `status ∈ {self-solved, learned, pending-review, reviewing}`，按逾期天数降序。
- 设置页加「重置本题 SRS」入口（写 `srsLevel=0, status=new, nextReviewAt=undefined`）。**澄清 PRD**：PRD F6 原文只说「重置 `srsLevel` 回 0」，但若保留 `status='mastered'`，复习队列（不含 mastered）永远看不到它，重置等于没重置；故同时置 `status='new'` 让它重新进「建议新题」。history/note/skeleton 不动。

## 不做
- 不做比 Anki 更复杂的算法（固定序列够用）。
- 不做逾期惩罚（照常补）。
