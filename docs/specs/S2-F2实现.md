# S2-F2 实现偏离/补充 — 贴题模式与 md 导入

## Context

S0 三件地基 + S1-F1 已落地。本轮做 S2-F2：首次打开某题 → 贴题面板（题面/模板/题解/用例），支持多选 `面试经典150题/*.md` 批量导入，示例正则解析为用例，skeleton 解析出判题入口 `entry`。

PRD F2 验收锚点：导入 `88. 合并两个有序数组.md` 后题面渲染、3 示例→用例、`entry={name:'merge',callType:'function'}`。实测 88.md 无 fenced 代码块、无 Python 块，故「Python 代码块进 skeleton.python」一条对当前文件不成立（文件本身无 Python），Python 路径用合成 fenced md 验证。

## 实现偏离/补充（对齐 S1-F1 做法，落地时确认）

### 1. 用例自动解析（spec 写「点按钮」→ 改为自动 + 保留按钮）
spec 实现要点把示例解析放在「点按钮」上。实测发现用户不会主动点、且把 JSON 用例编辑器当主输入被吓到。改为：**题面变化时自动 `parseExamples` 填用例**（仅当前无用例时，避免覆盖手动编辑；400ms 防抖），`savePaste` 兜底再解析一次（防贴完立刻点贴好了、自动解析未触发）。保留「重新解析」按钮（覆盖前二次确认）。

### 2. 折叠技术细节（spec 未规定 UI 布局）
判题器内部格式（JSON 字面量 args、outArg）原本直接摆在用例表里，用户反馈「不知道怎么填」。改为：主路径只露 ① 题面 + ② 默认语言模板 + 「贴好了」；JSON 用例编辑器/outArg 折进「手动调整用例」、另一语言模板折进「也填 X 模板」、题解折进「③ 题解」。用例识别后以绿字摘要 + 预览展示，不露 JSON。

### 3. 编辑题目逃生口（spec 未提，补死锁修复）
spec 只说贴题面板可增删改用例，但刷题阶段用例表是只读（原型遗留），且一旦带着空用例进了刷题阶段就回不去 → 死锁。补：刷题/看题解/完成阶段题头加「编辑题目」按钮回贴题面板并回填字段；**默写阶段不开放**（避免借机看题解）。`savePaste` 仅**首次贴题**（`!problem.statement`）把编辑器重置为 skeleton，从刷题阶段回去补用例再贴好了不清空用户已写代码。

### 4. 裸代码兜底（spec 只讲 fenced 块）
spec 代码块约定只覆盖 fenced 块。真实 88.md 无围栏，只有裸 `var merge = function...`。补：无任何 fenced 块时按函数定义特征识别一段裸代码作 skeleton（取到文件尾），用冒号/花括号区分两种语言的 `class Solution`（避免 JS `class Solution {` 被误判为 Python），Python 分支 `class\s+Solution\b.*:` 兼容 `class Solution:` 与 `class Solution(object):`。

### 5. 题号正则放宽
spec 写 `^(\d+)\.`，实现用 `^(\d+)`（不要求点号）。宽松是故意的，selftest 覆盖 `123abc.md`→123。

### 6. 批量导入健壮性
- 题库外题号：store 会静默忽略，但计数不能虚高 → 用 `useProblems()` 建合法 id 集合，命中才落库/计数，否则计 skipped。
- `file.text()` try/catch：单文件读取失败计 skipped、继续其余，不让整批 abort。
- 文件选择器 `e.target.value = ''`：重选同一批文件能再触发。
- 当前题命中则回填面板字段供微调。

### 7. 「重新解析」覆盖前确认 + 反馈
已有用例时 `window.confirm` 二次确认；解析到/没解析到都给 `importMsg` 提示。

### 8. `ParsedProblem.solution` 死字段保留
`extractBlocks` 不返回 solution（代码块→skeleton，题解可稍后补），导入永不填题解。字段保留以对齐接口形状，符合 PRD「题解可稍后补」定位。

## 涉及文件
- `src/lib/entry.ts`（新建）— `parseEntry(skeleton, lang)`：class Solution→method，自由函数→function（def/function/var=func/箭头），失败→undefined
- `src/lib/import.ts`（新建）— `parseMdFile`/`parseExamples`/`parseIdFromFilename`：fenced 块约定 + 裸代码兜底 + 示例正则（顶层逗号切分、剥 `变量名 =`、JSON 规范化）

- `src/pages/ProblemView.tsx` — 贴题面板接持久化 + 自动解析 + 折叠 + 编辑题目逃生口 + 批量导入
- `scripts/selftest-s2.mts`（新建）— entry/import 解析自测（48 项）
