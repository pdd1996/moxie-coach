# S4-F4 默写模式 + S5-F5 一句话笔记 —— 合并实现计划

## Context
S3-F3(尝试)已完成。下一步 F4(默写)与 F5(笔记)在 `ProblemView.tsx` 是同一条用户流(默写通过 → SRS 结算 → 弹笔记 → done),且持久化都挂在「当次 history / problem 字段」上,合并实现避免同一处改两遍。

当前 reproduce 阶段 UI 占位齐全(题解收起、笔记常驻、偷看弹窗、通过/失败按钮、笔记弹窗),但**持久化基本是空的**:
- 默写通过/失败不记 history、不调 SRS、不改 status/srsLevel/nextReviewAt
- `peekCount` 只在本地 state,未写进当次 history
- `note` 不落盘(`saveNote` 没调 `updateProblem`)
- "先跳过"只关弹窗、不进 done(用户卡在 reproduce)
- 无"到期复习直进默写 + status=reviewing"入口
- 题单/仪表盘复习入口看不到笔记

目标:把 F4 的判题/SRS 结算 + F5 的笔记弹窗一起接上持久化。按 F4、F5 分两次 commit。

## 关键复用
- `passSchedule` / `failSchedule` / `todayStr` — `src/lib/srs.ts`(已就绪,无人调用)
- `reviewQueue` 的到期口径 `nextReviewAt <= today && REVIEWABLE_STATUSES.has(status)` — `src/lib/srs.ts`
- `AttemptHistory.phase: 'attempt'|'reproduce'|'review'` — `src/lib/types.ts`(已含 review,无人写)
- `recordAttempt` 模式(append history + SRS 结算) — `ProblemView.tsx`,reproduce 照抄同款
- store `updateProblem(id, patch)` 浅合并 + debounce 落盘 — `src/lib/store.tsx`

## 语义决策(已确认)
复习通过:**保持 self-solved**(只升 srsLevel/排期,达顶才 mastered);learned/pending-review/reviewing 复习通过 → learned(达顶 mastered)。spec 字面"复习通过→learned"按此修正,保留自解荣誉与自解比例统计。
**失败即降级、不再恢复**:自解题复习失败 → status=pending-review(离开 self-solved);此后再复习通过 → learned,不再回到 self-solved。靠 mount 快照 `entryWasSelfSolved`(进入时是否自解)区分,而非实时 `problem.status`(失败后已变)。

## 改动 1 — F4:reproduce 结算 + 复习入口(`src/pages/ProblemView.tsx`)

### 1a. 入口判定:到期复习直进 reproduce
- 新增 `REVIEWABLE_STATUSES` 引用(从 srs 或本地常量),mount 时算 `isReviewEntry`:
  `problem.statement && problem.nextReviewAt && problem.nextReviewAt <= todayStr() && REVIEWABLE_STATUSES.has(problem.status)`。
- `phase` 初始化改为:`isReviewEntry ? 'reproduce' : (statement ? 'attempt' : 'paste')`。
- 新增 `reproducePhaseTag` state(`'reproduce' | 'review'`):mount 时 `isReviewEntry ? 'review' : 'reproduce'`;`enterReproduce()`(从 solution 态,首次)置 `'reproduce'`。
- 新增 `entryWasSelfSolved` state(mount 快照):`isReviewEntry && problem.status === 'self-solved'`。复习 effect 对 self-solved 不覆盖,故暂停/恢复后 status 仍是 self-solved,快照始终为真 → 通过保持 self-solved;一旦失败 status 被改成 pending-review,下次进入快照为假 → 通过变 learned(**失败即降级,不再恢复**)。`enterReproduce()` 显式置 false(本轮看过题解,通过算 learned 而非保持 self-solved)。
- 新增 `settledRef = useRef(false)`:本次默写是否已结算。笔记弹窗为必经步,任何途径回到 reproduce 都不得二次结算;`onReproducePass`/`onReproduceFail` 入口 `if (settledRef.current) return` 守卫,结算时置 true。`enterReproduce()` 复位为 false(新一轮默写)。
- 新增 effect:phase==='reproduce' && isReviewEntry && status 不在 {reviewing, self-solved} → `updateProblem({status:'reviewing'})`(参照现有 attempt→in-progress effect 的"不覆盖"写法)。**关键修正：self-solved 也不覆盖**——否则持久化后暂停/恢复会丢失自解标记，结算时降级成 learned。自解题复习时保持 self-solved(badge 显示自解、仍在复习队列)，通过结算再判定升/降级。失败由 `onReproduceFail` 改成 pending-review，故「失败即降级」靠 status 离开 self-solved 实现。

### 1b. 偷看计数写进 history
- 偷看按钮 `peekCount++` 保持(本地态)。最终在结算时把 `peekCount` 塞进当次 history,不每次偷看都写(spec:"写入当次 history")。

### 1c. 通过/失败结算(照抄 `recordAttempt`/`selfSolved` 模式)
- `recordReproduce(outcome)`:append history,`phase = reproducePhaseTag`,`peekCount = peekCount`(当前本地态)。
- `onReproducePass()`(`!allPass` 或 `settledRef.current` 时直接 return,按钮已 disabled):
  - `settledRef.current = true`(防二次结算)
  - `sched = passSchedule(problem.srsLevel, settings.intervalsDays, todayStr())`
  - `recordReproduce('pass')`
  - status:`sched.mastered ? 'mastered' : (entryWasSelfSolved ? 'self-solved' : 'learned')`(用 mount 快照而非 `problem.status`——失败后 status 已变 pending-review,靠快照区分「自解复习通过」与「失败后重写通过」)
  - `updateProblem({ status, srsLevel: sched.srsLevel, ...(sched.nextReviewAt ? {nextReviewAt} : {}), lastLang: lang })`
  - `openNote('pass')` → S5
- `onReproduceFail()`(`settledRef.current` 时直接 return):
  - `settledRef.current = true`
  - `failSchedule(...)` → srsLevel=0、nextReviewAt=+intervalsDays[0]
  - `recordReproduce('fail')`
  - `updateProblem({ status:'pending-review', srsLevel:0, nextReviewAt, lastLang: lang })`(status 离开 self-solved → 下次通过不再恢复自解,降级为 learned)
  - `openNote('fail')` → S5
- reproduce 按钮 onClick 从 `openNote` 改为 `onReproducePass` / `onReproduceFail`。

### 1d. done 屏 mastered 文案 + 失败分支真实天数

- done 层 pass 分支:`problem.status === 'mastered'` 时显示"间隔走完,已掌握 —— 不再排期复习",否则显示"已排期 {nextReviewAt} 复习,下次直接默写"(`nextReviewAt` 现在是真值,不再是 '3 天后' 兜底)。
- done 层 fail 分支:用 `reviewInDays`(从 `problem.nextReviewAt` 推算 `Math.max(1, round((nextReviewAt - today)/1d))`)显示"{reviewInDays ?? 3} 天后再战",与 `intervalsDays` 解耦——失败当下 = intervalsDays[0],跨天回看 done 屏也准确,改设置后展示与实际排期一致。

## 改动 2 — F5:笔记持久化 + 跳过修复(`src/pages/ProblemView.tsx`)

### 2a. saveNote 落盘 + 弹窗非关闭

- `saveNote()`:`note.trim()` 非空才 `updateProblem(problem.id, { note: trimmed })`(避免空串擦除已有 note),随后 `setNoteOpen(false)` + `setDoneKind('reproduce')` + `setPhase('done')`。
- "先跳过"按钮:改为 `skipNote()` = `setNoteOpen(false)` + `setDoneKind('reproduce')` + `setPhase('done')`(不写 note,保留库中已有 note 不擦除)。
- 注:结算(status/history)已在 1c 的 pass/fail 时完成,笔记只是可选后置步骤;跳过不影响结算。
- **笔记弹窗为必经步,屏蔽 X/遮罩/Esc**:`DialogContent` 设 `showCloseButton={false}`、`onEscapeKeyDown={e => e.preventDefault()}`、`onInteractOutside={e => e.preventDefault()}`。理由:弹窗是结算后回到 done 的唯一通道,若允许 X/遮罩/Esc 关闭会落回 reproduce,配合 `settledRef` 已置 true 会导致通过/失败按钮失活(看似卡住)。只能经「保存笔记/先跳过」退出,与 `settledRef` 守卫共同保证不二次结算。

### 2b. 复习入口可见笔记
- `src/pages/ProblemList.tsx` `ProblemRow`:有 `p.note` 时在标题/状态列加 `StickyNote` 图标,`title={p.note}`(tooltip),复用现有 `title=` 模式,免引 Tooltip 组件。
- `src/pages/Dashboard.tsx` 复习队列 Link:有 `p.note` 时加同款 StickyNote 图标 + title。

### 2c. ProblemNote 组件
- spec 列 `src/components/ProblemNote.tsx`(可内联)。现有 reproduce 顶部 + done 层两处笔记展示已是内联,保持内联,不抽组件,避免无谓扩散。如后续需统一再抽。

## 验证
启动 dev server(`moxie-coach` 下 `npm run dev`),浏览器走两条路径:
1. **首次默写**:贴题 → attempt → 看题解 → 进默写 → 偷看 N 次 → 跑通用例 → 默写通过 → 弹笔记 → 写笔记保存 → done。核对 db.json:status=learned、srsLevel=0、nextReviewAt=+3、history 末条 phase=reproduce/outcome=pass/peekCount=N、problem.note 有值。
2. **复习默写**:把上一题 nextReviewAt 改今天 → 刷新仪表盘,该题进复习队列 → 点进 → 直进 reproduce(题解收起、笔记常驻、不重看题解)→ 跑通 → 通过 → done。核对:**自解题 status 保持 self-solved**(不置 reviewing);非自解(learned/pending-review)才变 reviewing、通过后变 learned。srsLevel+1、history phase=review、nextReviewAt=+7。
3. **失败路径**:默写失败 → 弹笔记(先跳过)→ done。核对 status=pending-review、srsLevel=0、nextReviewAt=+3、history outcome=fail;note 未被擦除。**弹窗期间 X/遮罩点击/Esc 均无法关闭**,只能经「保存笔记/先跳过」退出。
4. **失败即降级不再恢复**:接上,把该题 nextReviewAt 改今天再进 → 通过 → done。核对 status=**learned**(不再回 self-solved,即便原是自解题)、history phase=review/outcome=pass。
5. **saveNote 空串不擦除**:笔记弹窗里清空文本框再保存 → done。核对 db.json 中 problem.note 保留旧值、未被空串覆盖。
6. **mastered**:把 srsLevel 调到 intervalsDays.length-1 再复习通过 → status=mastered、done 层显示"已掌握"。自解题走 attempt 自解通过达顶同样判 mastered(附带修复)。
7. 题单/仪表盘:有 note 的题行显示笔记图标,hover 出 note 文案。
