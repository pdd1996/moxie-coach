# S9-F9 — 数据管理 UI（P0 · 对应 PRD F9）

## 目标
设置页提供导出/导入 db.json、清空全部数据（二次确认）。备份与原子写入由 S0-data-layer 实现，本 spec 只做用户入口。

## 验收标准（来自 PRD F9）
- 导出 → 清空 → 导入 可完整还原。
- 「清空全部数据」需二次确认。
- 设置页可见备份目录说明（每日自动备份、保留 30 份）。

## 数据读写点
- 导出：`GET /api/db` → 下载 `db.json`
- 导入：读用户文件 → 校验结构 → `PUT /api/db`
- 清空：`PUT /api/db` 写空种子（仅 settings + 空 problems）

## 涉及文件
- `src/pages/Settings.tsx` — 数据管理分区（原型已有设置页骨架）
- `src/lib/store.ts` — `exportDb` / `importDb` / `clearDb`

## 依赖前序 spec
S0-data-layer（备份/原子写入/导入导出底层）

## 实现要点
- 导出：拉全量 db 存为文件下载。
- 导入：读文件 → `JSON.parse` → 校验顶层有 `settings`/`problems` → PUT。校验失败给明确报错，不覆盖现有数据。
- 清空：二次确认对话框（输入「确认」或点确认按钮），清成初始种子。
- 备份列表：设置页只读展示 `data/backups/` 里最近几份（可选，通过一个 `/api/backups` 列目录；若复杂度不值当则只文字说明）。

## 不做
- 不做云同步/导出到云。
- 不做单题级导入导出（整库为单位）。
