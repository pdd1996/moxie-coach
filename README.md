# 默写教练 · moxie-coach

> **能默写出来，才算会。** 看懂 ≠ 会写，只有关掉题解能从头写到跑通，套路才算进了手。

个人刷题纪律工具 + 可选的 AI 教练。不是又一个刷题网站--题库就是 LeetCode「面试经典 150 题」--而是套在这 150 题外面的一层**流程引擎**：把一套验证过的方法论用软件强制执行。

转行刷题的痛点从来不是「缺题库」，而是**缺纪律和反馈闭环**：看题解时「眼睛会了」、不复习导致白刷、跳着刷导致套路建立不起来。这个工具就是治这三个病的。

## 小白怎么刷题：五条心法

所有功能都围绕这五条设计（方法论完整版见 [docs/刷题技巧.md](docs/刷题技巧.md)）：

1. **刷题不是学数学，是攒「手感」。** 转行面试考的算法题 80% 是套路题，不需要天赋，需要见过的题量。没写过 ≠ 学不会，只是还没开始。
2. **按「套路」分组，别按「数量」刷。** 双指针做 5 道，胜过随机刷 50 道；今天数组明天 DP，套路永远建立不起来。
3. **看懂 ≠ 会写。** 光看题解点头「懂了」不算会，关掉题解能默写到跑通才算会。
4. **卡住有上限，别死磕。** 自己想 15–20 分钟想不出就看题解。Easy 给 15 分钟，Medium 给 20–25 分钟--重点是「卡住就停」，不是数字本身。
5. **不复习等于白刷。** 错题 3 天后重做（艾宾浩斯遗忘曲线），还记得才变成长期记忆。

另外固定一门语言：转行推荐 Python（代码短、写得快）或 JavaScript（前端方向）。工具双语言都支持，选一门别换。

## 默写循环：每道题的标准流程

```
自己想 15–20 分钟 -> 想不出看题解 -> 关掉题解从头默写到跑通
-> 一句话笔记「什么时候用这个套路」-> 3 天后重做 -> 掌握
```

为什么每一步都不能省：

- **先自己卡一下**--不自己卡一下，脑子不会真正「接住」这个套路；直接看题解，知识只停留在眼睛里。
- **想不出就看题解**--转行不考难题怪题，超时还死磕是性价比最低的事。
- **关掉题解默写**--这一步是分水岭。能从头写到跑通，才说明套路进了你的手，不只是进了眼。
- **隔 3 天再做一次**--不复习等于白刷，3 天后还记得才变成长期记忆。

一句话记住：能默写出来，才算会。这条做到了，其它都是顺水推舟。

## 四阶段路线（12 周 / 150 题）

| 阶段 | 周次 | 主题 | 代表题 |
|------|------|------|--------|
| 1 | 第 1–3 周 | 数组 / 字符串 / 双指针 / 滑动窗口 / 哈希表 | #88 #1 #3 |
| 2 | 第 4–6 周 | 链表 / 栈 / 二叉树 | #206 #21 #102 |
| 3 | 第 7–9 周 | 二分查找 / 矩阵 / 图 / 堆 | #704 #200 #347 |
| 4 | 第 10–12 周 | 动态规划 / 贪心 / 回溯 | #70 #322 #46 |

题库按这四个阶段内置，仪表盘建议新题时不跨阶段。每天 1–2 道，稳定 > 爆发。

## 避坑清单

- ❌ 追求题量、不复习 -> 白刷
- ❌ 看题解点头「懂了」 -> 默写不出就是没懂
- ❌ 跳着刷，今天数组明天 DP -> 套路建立不起来
- ❌ Hard 死磕 1 小时 -> 超 20 分钟看题解
- ❌ 切换语言 -> 固定一门
- ✅ Easy 全做、Medium 选做、Hard 跳过或只看题解
- ✅ 每天 1–2 道，稳定 > 爆发
- ✅ 3 天后重做错题

## 这套理念怎么被软件执行

| 理念 | 软件怎么执行 |
|------|--------------|
| 按套路分组、不跳着刷 | 内置 156 题元数据（面试经典 150 题 + 套路代表题），按四阶段 × 套路分组；仪表盘只按阶段顺序建议新题 |
| 卡住有上限 | 打开题目自动计时（Easy 15 / Medium 20 / Hard 25 分钟，可配置），到点提醒该看题解了，软约束不锁死 |
| 看懂 ≠ 会写 | 默写模式：题解收起、代码清空只留函数签名、重新计时；允许「偷看一眼题解」但如实记录次数--工具不撒谎 |
| 不复习等于白刷 | SRS 间隔复习引擎：默认 3 / 7 / 14 天排期（可配置），到期复习直接进默写不重看题解；失败则等级清零、3 天后从头再来 |
| 一句话笔记 | 默写结束必经笔记弹窗，固定提示语「什么时候用这个套路？」；复习时先看笔记再默写 |
| 真判题 | 浏览器内 Pyodide 跑 Python、Web Worker 跑 JS，用例真跑真比对（宽松比对：集合类型忽略元素顺序） |
| 数据自主 | 所有数据是磁盘上的明文 `data/db.json`，每日自动备份（保留 30 份），可随时导出/导入，不锁定 |

进度页另有 GitHub 风格打卡热力图、默写一次通过率、独立解出率、套路掌握进度--这些数字只统计真实发生的行为（自解通过 / 超时看题解 / 偷看，各记各的）。支持深色模式。

## AI 教练四件套（可选）

AI 的定位是**教练，不是答案机**：它的工作是保住「自己卡一下」的价值，而不是替你写。

- **卡住提示** -- 按「找入口三步法」分三层递进：第 1 层引导你手算一个例子，第 2 层引导你观察自己刚才的动作，第 3 层才点破陷阱。每层都禁止输出代码，连要 3 层只会劝你去看题解。
- **边界审查** -- 默写通过后按「边界三问」（越界 / 空输入 / 极端数据）审你的代码，只挑毛病、不给修复代码，并输出恰好 3 个攻击用例一键入库，修改靠自己。
- **题解生成** -- 本地没贴题解时按固定模板流式生成：套路名 / 判断信号 / 找入口三步法 / Python + JS 双语言模板 / 边界三问，可一键保存。
- **错题提示卡** -- 默写失败后自动生成一张不超过 40 字的提示卡，下次默写时展示，通过了就清除。

不填 API key 时所有 AI 入口自动隐藏，其余功能完整可用。默认 DeepSeek（OpenAI 兼容协议），在应用内「设置」页配置 baseUrl / apiKey / model，key 只存本地 `data/db.json`，前端不持有。

## 快速开始

需要 Node >= 18。

```bash
npm install                      # 首次
node scripts/setup-pyodide.mjs   # 一次性：本地打包 Pyodide（浏览器内判 Python 必需，不入库）
npm run dev                      # http://localhost:5173
```

- **题从哪来**：不内置任何题面/题解（版权原因）。打开题目后自己贴题面、代码模板、题解，示例会自动解析成测试用例；也支持把本地 LeetCode 笔记 md 批量导入。
- **AI（可选）**：设置页填 DeepSeek 或任意 OpenAI 兼容服务的 key 即可，无环境变量。
- **使用形态**：面向本机 dev server 的单用户工具，数据全在 `data/db.json`（首次启动自动生成演示种子）。`npm run build` 产物是纯静态站，不含数据中间件。

## 技术栈

TypeScript 全栈 · React 19 + Vite 8 · react-router 7 · Tailwind CSS v4 · shadcn/ui · CodeMirror 6 · react-markdown
判题：Pyodide（本地 vendored、离线可用、超时可中断）· Web Worker（JS 用例隔离执行）
后端：无独立服务器，Vite dev 中间件三件--`/api/db` 读写 db.json（原子写入 + 每日备份）、`/ai-api` OpenAI 兼容流式代理（key 从本地 db.json 现读，前端不持有）、`/pyodide/*` 静态服务 + 跨源隔离头
工程：oxlint · 纯函数自测脚本（`scripts/selftest-*.mts`）· Playwright 浏览器冒烟（`scripts/smoke-*.mjs`）
